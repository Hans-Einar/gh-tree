# Bounded BC specialization evidence

These exact sources/captures support #55 contract authoring; they are not product
code or executed product verification. Python source ends `.py.txt` so it cannot
accidentally become an executable product input. Reproduction belongs in a new
owned temporary directory with isolated Git config, never a user repository.

Commit/PROTOCOL.md describes the native private commit/hook/signing/HEAD-first
transaction/index publication specialization. Its25 final cases passed; a prior
harness failure is preserved separately. The signing fixture is deliberately
noncryptographic. Upstream tagged C-source hashes/links are retained in the manifest
and protocol; upstream source itself is not copied into the project. Five owned
protocol/probe/result files match their eight-file original manifest subset.

Batch records a native Windows .cmd carrier using a temporary ordinary shim that
forwards argv to a diagnostic process. It preserves tested colon, whitespace,
Unicode, ampersand, parentheses, exclamation, trailing slashes and empty arguments;
unsupported quote/percent/control grammar is explicitly rejected. Actual package
manager shims and full Runtime integration remain implementation verification.

Archive attributes preserve original byte hashes, including native line endings.
No native executable, signing key, real repository data or account credential is
included. Freeze/review must assess actual protocols and limits rather than treating
these bounded mechanisms as all-platform production success.
