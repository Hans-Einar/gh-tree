AnyVM uses a builder-provided SSH key, disables host-key checking, and by default
binds control SSH to localhost plus detected private host addresses. Before VM
startup, new non-loopback inbound TCP is denied in both host IPv4/IPv6 INPUT
chains, while established download traffic continues. Evidence checks both rules
remain and records actual listening addresses/ports. This is disposable-runner
network restriction, not isolation from malicious dependency code with host sudo.
No public ports, remote debug/VNC, sshfs or guest-to-host SSH authorization are
requested; source inspection shows those authorization paths require sshfs or
accept-vm-ssh/debug. Rsync also avoids host-mounted filesystem semantics.

The action implicitly sends GITHUB_* and CI through SSH (not the entire host
environment). No token/secret is supplied by this workflow and checkout does not
persist credentials. The ordinary test process clears even those inherited
metadata variables. Downloaded control code still executes on a hosted runner
with ordinary Actions runtime privileges; independent review must assess this
specific trust boundary, not infer safety solely from disabled VNC.
